# Simulated Autos for review — 1 Oct 2026

Eight simulated AUTO periods, red alliance, two robots each. Every folder holds the `.wpilog`
of one run and the Auto Builder `.pp` files that produced it.

## Where these come from

Nothing here is drawn by hand, and AdvantageScope did not produce it. AdvantageScope only *views*
the logs. The simulation is the team's own test code:

1. A route is drawn as a `.pp` file in the Auto Builder. Most of these were generated by the
   scripts in `tools/auto-routes/`.
2. The Auto Builder's exporter turns each `.pp` into a Java Auto, in
   `TeamCode/src/test/java/.../opmodes/auto/generated/`.
3. `AutoSim` (`TeamCode/src/test/java/.../logging/AutoSim.java`) runs that Java Auto through
   the same `autokit` code the robot runs.
4. It drives a simulated robot on a simulated field, `FieldSim`: pieces, launches, the HIVE
   tipping as FIRST's calibration says it should, and spills.
5. It writes everything to a `.wpilog`.

These are simulations. HIVE tipping follows the published calibration. Tile friction, bounce,
shot scatter and how fast a CELL swings are placeholders until we measure them. Treat the numbers
as comparisons between plans, not predictions of match scores.

## Viewing a log in AdvantageScope

1. Open the `.wpilog`.
2. Open a **3D Field** tab on the 2026-2027 field.
3. Drag `/Odometry/AllRobots3d` onto the field as a **Robot** to see both robots at once.
4. To tell them apart, drag `/Odometry/Robot3d` as a Robot and `/Odometry/Partner3d` as a
   **Ghost** in another colour. The Metadata tab says which Auto each robot ran.

For the moving HIVE: pick the field **2026-2027 Field (HIVE sim)**, drag `/Sim/Hive/Structure` as a
Robot with model **BIOBUZZ HIVE**, and drop `/Sim/Hive/Components` onto that row as **Component**.
For the pieces: drag `/Sim/GamePieces/Pollen`, `RedNectar`, `BlueNectar` and their `Held/` versions
as Game Pieces. That needs a one-time asset setup: see `TeamCode/README.md`,
"Game pieces and the HIVE in a simulated .wpilog".

## Regenerating or checking a run

From the repository root, on this branch, with the Android SDK set up (`ANDROID_HOME`):

```
BIOBUZZ_AUTO_STUDY="LeanOppSouthAuto,LeanOppNorthAuto@50" \
BIOBUZZ_AUTO_DESIGNS="clump catapult 72 deg, 24 in catcher" \
BIOBUZZ_AUTO_SEEDS=6 BIOBUZZ_AUTO_TIMELINE=6 \
./gradlew :TeamCode:testDebugUnitTest --tests '*AutoStudyTest*' -i
```

That reruns folder 1 and prints its timeline. The log lands in `TeamCode/build/sim-logs/`, which
git ignores; that is why only these copies are committed.

For the runs with a typical partner (folders 5–8), add
`BIOBUZZ_AUTO_PARTNER_SPEED=40 BIOBUZZ_AUTO_PARTNER_DESIGN="spring hood"`. The study names are
`DuoLzSouthAuto,DuoLzNorthAuto`, `ThreeTipAdaptiveAuto,PartnerPreloadsParkAuto`,
`ThreeTipAdaptiveAuto,PartnerLeaveParkAuto`, `ThreeTipAdaptiveAuto,PartnerPreloadsNorthTimerAuto`
and `NorthFirstAuto,PartnerPreloadsSouthAuto`, each `@50`. Design names are listed in
`AutoStudyTest.designs()`.

The `.pp` files here are copies. The ones the code uses are in
`TeamCode/src/test/resources/auto-builder/` (partners in `partners/`).
