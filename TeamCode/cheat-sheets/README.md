# Cheat-sheet logos

The printable controller sheets are generated by `CheatSheetTest` from `controls/ControlScheme`
into `TeamCode/build/cheat-sheets/` (`./gradlew testDebugUnitTest`, then open and print, portrait).

The sheet header uses the team's logo from this folder: `logo-19429.jpg` (Infrared) and
`logo-20245.jpg` (Ultraviolet), the wordmarks from the team's BioBuzz Strategy Map deck. A `.png`
or `.svg` with the same name works too; a wide wordmark on white prints best. Without one, the
sheet draws the team number on the team's colours.
